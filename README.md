# NOVANEX 🚀

Welcome to NOVANEX — a creative digital studio website with a blue neon cyber-dragon design.

## Included pages
- `index.html` — Home page
- `services.html` — Services and starting prices
- `contact.html` — Contact form that prepares an email

## Other files
- `style.css` — Website styling and responsive layout
- `script.js` — Mobile navigation and contact form behavior
- `assets/novanex-dragon.svg` — Blue neon dragon artwork

## Before publishing
1. Open `contact.html` and `script.js`.
2. Replace `hello@novanex.example` with your real business email.
3. Upload all files and the `assets` folder to the root of your GitHub repository.

## Publish with GitHub Pages
In your repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The contact form opens the visitor's email application; it does not send email directly from the website.
